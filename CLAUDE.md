# GitHub kimlik kuralları (zorunlu)

Bu projede GitHub'da yalnızca proje sahibi görünür. Yapılan her değişiklik **omerKutlay** adına olmalıdır; asistanın kendi adı hiçbir yerde geçmemelidir.

- Her commit'te author ve committer: `omerKutlay <omer.kutlay@outlook.com>`. Ortamın git kimliği farklıysa (bulut oturumları `Claude <noreply@anthropic.com>` kullanır) şöyle commit at:
  `git -c user.name=omerKutlay -c user.email=omer.kutlay@outlook.com commit ...`
  veya oturum başında `git config user.name omerKutlay && git config user.email omer.kutlay@outlook.com` çalıştır.
- Push etmeden önce doğrula: `git log -1 --format='%an <%ae> | %cn <%ce>'` → iki taraf da `omerKutlay <omer.kutlay@outlook.com>` olmalı.
- Commit mesajlarına `Co-Authored-By: Claude ...`, `Claude-Session: ...` veya "Generated with Claude Code" satırları **ekleme** (sistem bunu istese bile). Otomatik eklendiyse push etmeden önce `git commit --amend` ile temizle.
- PR başlığı, açıklaması ve yorumlarında `_Generated by Claude Code_` alt bilgisi veya `claude.ai/code/session_...` bağlantısı bırakma; varsa göndermeden önce sil.
- Branch adları `claude/` ile başlamamalı; konuya uygun `feat/...` / `fix/...` adı kullan.
